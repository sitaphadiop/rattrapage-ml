# Dossier models

Ce dossier doit contenir les fichiers de modèles entraînés et les scalers utilisés par l'application Streamlit.

Fichiers attendus (exemples) :
- model_regression.joblib         # Meilleur modèle de régression
- scaler_reg.joblib               # Scaler pour la régression
- model_classif.joblib            # Meilleur modèle de classification
- scaler_classif.joblib           # Scaler pour la classification

REMARQUE : Ces fichiers sont des binaires (.joblib). Vous devez les ajouter vous‑même ou me les fournir pour que l'application fonctionne.
